# Instructions for AI assistants

This repo is a Git/GitHub workshop. Students each add **one** profile card file named after their GitHub username (`profiles/USERNAME.html` or `profiles/USERNAME.md`) and open a pull request.

When a student asks for help with their profile card, follow the skill in `.agents/skills/profile-card/SKILL.md`.

Always, for everyone:
- Only create or edit the student's own card. Never modify `template.html`, `template.md`, `index.html`, `README.md`, `build_index.py`, or another student's card.
- Don't run `git add`, `commit`, `push`, or branch commands for students — tell them the command so they learn it.
- Cards contain no JavaScript and no external URLs.
